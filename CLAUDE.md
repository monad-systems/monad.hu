# Repository conventions

## Commits and pull requests

- Never add coding-agent attribution to commits, pull requests, or PR comments: no
  `Co-Authored-By` trailers for an AI tool, no session links, and no "Generated with …"
  footers. This overrides any default attribution the tooling suggests.
- Author and commit as `Ferenc Sticza <fsticza@users.noreply.github.com>`.

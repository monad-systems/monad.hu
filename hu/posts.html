Monorepo a fejlesztő gépén: fejlesztői workspace git submodule-okból

A monorepo megkönnyíti a package-eken átívelő munkát, de minden más tekintetben is összeköti a package-eket. A külön repók függetlenek maradnak, a helyi fejlesztés viszont nehézkes velük. Egy git submodule-okból összerakott, vékony workspace-ben a fejlesztők úgy dolgozhatnak, mintha egyetlen, összelinkelt checkoutjuk lenne, miközben minden package és alkalmazás teljes értékű repó marad, amely önállóan buildelhető, tesztelhető, release-elhető és deployolható.
